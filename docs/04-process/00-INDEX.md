# 04-process: Procesos y Convenciones de Trabajo

Punto de entrada para estándares de código, trabajo colaborativo con agentes de IA, criterios de calidad y resolución de incidencias en **Samsar | Sitio web personal**.

---

## 1. Contenido de esta sección

| Archivo | Qué define | Cuándo consultarlo |
|---|---|---|
| [`01-conventions.md`](01-conventions.md) | Convenciones de idioma, TypeScript, estilos Tailwind y formato de ramas y Conventional Commits. | Antes de redactar código, crear componentes o escribir mensajes de commit. |
| [`02-working-with-agents.md`](02-working-with-agents.md) | Guía pedagógica para estudiantes sobre cómo dirigir, auditar y colaborar con agentes de IA. | Al iniciar una sesión de trabajo con Claude Code, OpenCode, Codex o Antigravity. |
| [`03-definition-of-done.md`](03-definition-of-done.md) | Lista de verificación rigurosa para declarar una tarea como terminada y lista para merge. | Antes de dar por finalizada cualquier tarea de `docs/05-tasks/`. |
| [`04-glossary.md`](04-glossary.md) | Glosario técnico de términos de arquitectura, estándares web y conceptos del proyecto. | Al encontrar términos como SSG, Islands, FOUC, Zod o WCAG. |
| [`05-troubleshooting.md`](05-troubleshooting.md) | Diagnóstico y solución rápida para los 5 problemas más comunes del stack técnico. | Cuando `bun run check` o `bun run build` arrojen errores o la pantalla parpadee. |

---

## 2. Orden de lectura recomendado

1. **`01-conventions.md`** (10 min): Conocer las reglas de nomenclatura y estilo de código.
2. **`02-working-with-agents.md`** (15 min): Entender el rol de liderazgo humano frente a la IA.
3. **`03-definition-of-done.md`** (5 min): Conocer los 7 criterios de calidad no negociables.
4. **`04-glossary.md`** y **`05-troubleshooting.md`**: Consultar como material de referencia cuando sea necesario.

---

## 3. Principio Fundamental de Proceso

> **El humano lidera, la IA ejecuta:** En este proyecto formativo, el objetivo principal no es solo que el software funcione, sino que el estudiante comprenda el porqué de cada decisión arquitectónica y domine el código que se integra al repositorio.
